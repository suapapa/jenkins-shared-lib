Register built OTA binaries with the update API for each HW revision. Injects <code>HOMIN_DEV_TOKEN</code> from a Jenkins Secret text credential (default id <code>HOMIN_DEV_TOKEN</code>; override with <code>credentialsId</code>). Prefers <code>release/upload_update.sh</code> when present.

Required: <code>version</code> (or <code>env.SW_VERSION</code>).

<pre><code>script {
  espRsOtaRegister(
    version: env.SW_VERSION,
    hwRevisions: ['3', '4'],
    sourceDir: 'release',
    binPrefix: 'rusty-hangulclock'
  )
}
</code></pre>
