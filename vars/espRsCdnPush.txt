Clone a CDN asset GitHub repository into the workspace with <code>gh repo clone</code>, copy versioned <code>.bin</code> files, commit, and push using the agent's pre-authenticated <code>gh</code> CLI.

Required: <code>assetRepo</code> (or <code>env.ASSET_REPO</code>) and <code>version</code> (or <code>env.SW_VERSION</code>).
Optional: <code>keepCount</code> (default: 0 = unlimited; when &gt; 0, keeps latest keepCount artifacts in assetSubdir via git rm).

<pre><code>script {
  espRsCdnPush(
    assetRepo: 'suapapa/homin-dev_asset',
    assetSubdir: 'asset/rusty-hangulclock_fw',
    version: env.SW_VERSION,
    sourceDir: 'release'
  )
}
</code></pre>
